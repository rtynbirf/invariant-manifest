## ЧТО ЭТО

Паспорт = место практики под печатью. Каждая из 120 позиций домена A (001–100 аудированные + 1001–1020 NEW) получила паспорт с пятью полями приказа хозяина:

| Поле | Что отвечает |
|---|---|
| УСЛОВИЯ ПРИМЕНИМОСТИ | когда/где/для кого практика живёт |
| ИЗМЕРИМЫЙ ЭФФЕКТ | числа из реестра или честное «что мерить» |
| ОГРАНИЧЕНИЯ | границы, выведенные из зрелости/типа/связей |
| СТОИМОСТЬ ВНЕДРЕНИЯ | оценка INIT: S/M/L с обоснованием |
| ВОСПРОИЗВОДИМОСТЬ | вердикт аудита + как проверить у себя |

## ТРИ НОСИТЕЛЯ ОДНОГО СОДЕРЖАНИЯ = ОДНО ДРУГОЕ НЕ ИСКЛЮЧАЕТ

1. **Документ** — `A-001.md … A-1020.md`: человекочитаемые паспорта (120 файлов).
2. **Таблица** — `PASSPORTS.csv`: те же места одной строкой, с печатями.
3. **Лента** — `PASSPORTS_TAPE.json`: sha256 каждого паспорта + печать реестра — для машин.

**ПЕЧАТЬ РЕЕСТРА ПАСПОРТОВ = `2365d292200ebd448ab26db5b416dd772d1ee7699b7ca02a58e2ef69e568335e`**
(sha256 списка «ID печать» по 120 позициям в порядке реестра; файл меняется = печать меняется = свидетель кричит)

## МЕХАНИЗМ = ФАЛАНГА

- 6 агентов × 20 паспортов, единый бриф `МЕХАНИЗМ_ФАЛАНГИ.md` = один механизм, шесть рук.
- Верификация = машина, не глаз: 120/120 файлов — 5 секций посимвольно, мета = реестру посимвольно, ВЕРДИКТ ровно один и последний, заглушек нет, пустых секций нет.
- Оценки разрешены только с пометкой «(оценка INIT)».

## ЧЕСТНЫЙ СЧЁТ (главное открытие такта)

- **119 из 120 паспортов говорят «НЕТ ЧИСЛА В РЕЕСТРЕ»** — реестр качественный, а не количественный. Единственное место с числами: A-002 агентная автоматизация (11% продакшен · 38% пилоты · Deloitte 2026).
- Значит «ИЗМЕРИМЫЙ ЭФФЕКТ» паспорта = не цитата, а **определение метрики**: что именно мерить, когда практика внедрена. Паспорт, который честно говорит «измерь это», сильнее паспорта, который выдумал «+37%».
- Стоимость: S = 27 · M = 70 · L = 23 (все — оценка INIT, ни одна не выдана за факт).
- Аудит: 100 позиций прошли аудит 2026-11-20 (KEEP 97 + 3 мягких вердикта); 20 NEW-позиций аудит не проходили — в паспортах это сказано прямо.
- Эвиденция «не указана в реестре» у 19 позиций — не укрыто, а названо.

## ГРАНИЦА ЧЕСТНОСТИ

Пропаспортирован домен A. Каталожные диапазоны B–J (101–1000) из атласа паспортов не имеют: на них нет нормализованного реестра с эвиденцией — а паспорт без эвиденции = выдумка. Домены B–J ждут своих sweeps: реестр → аудит → паспорта. Честное отсутствие = добродетель.
