## УСЛОВИЯ ПРИМЕНИМОСТИ
Метод применяется там, где поведение оптимизируется через пробу, ошибку и награду: классические задачи управления и современное дообучение агентов. По реестру зрелость — массовая практика, эвиденция High, охват «классика плюс современный RL»; метод назван фундаментом для многих агентных практик. Адресат — команды, у которых есть среда с измеримой наградой и циклом взаимодействия.

- Реестр задаёт роль фундамента для агентных практик: изолированное применение без связи с ними теряет ценность.
