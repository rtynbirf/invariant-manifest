## УСЛОВИЯ ПРИМЕНИМОСТИ
Применимо для сельскохозяйственных и ремесленных цепочек с малыми производителями и развитым потребительским рынком, готовым платить за стандарт. Наиболее уместно для кофе, какао, чая, хлопка, бананов и сходных культур. Требует организации производителей в кооперативы, аудита и разделения премиального потока.

## ИЗМЕРИМЫЙ ЭФФЕКТ
НЕТ ЧИСЛА В РЕЕСТРЕ. Что мерить:
- Премия Fairtrade, полученная кооперативами за период
- Доля продаж по сертифицированному каналу
- Соответствие требованиям аудита по годам

## ОГРАНИЧЕНИЯ
- Сертификация не гарантирует справедливый доход (living income) для всех участников (оценка INIT)
- Издержки аудита тяжелы для малых кооперативов (оценка INIT)
- Премиальный рынок ограничен, избыток сертифицированного объёма не находит покупателя (оценка INIT)

## СТОИМОСТЬ ВНЕДРЕНИЯ
оценка INIT: S-M — аудит и соответствие для кооператива; для бренда — просто закупка по схеме.
