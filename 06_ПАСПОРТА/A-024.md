## УСЛОВИЯ ПРИМЕНИМОСТИ
Метод для команд, уже владеющих TDD и автотестами: добавляет генеративные проверки инвариантов поверх примерных тестов. Зрелость Deployed и семейство инструментов Hypothesis / QuickCheck делают метод доступным для соответствующих стеков. Наиболее ценен там, где есть чистые функции с проверяемыми инвариантами: парсеры, сериализация, преобразования данных.

## ИЗМЕРИМЫЙ ЭФФЕКТ
НЕТ ЧИСЛА В РЕЕСТРЕ. Что мерить: число инвариантов, проверяемых генеративно; долю дефектов, найденных генеративными тестами сверх примерных; время прогона генеративного набора.

ЧИСЛА SWEEP (2026-11-20, WebSearch): агент Anthropic (Claude + property-based testing) применён к 100+ популярным пакетам PyPI: подано 984 баг-репорта; при ручной проверке 50 репортов 56% оказались валидными багами, среди топ-ранжированных — 86% — источник: anthropic.com.

## ОГРАНИЧЕНИЯ
- Главный барьер — умение формулировать инварианты: без них метод не даёт пользы (оценка INIT).
- Метод дополняет примерные тесты, а не заменяет их (связи 023 и 891 в реестре).
- Эвиденция Medium: эффект сильно зависит от качества выбранных свойств (оценка INIT).
