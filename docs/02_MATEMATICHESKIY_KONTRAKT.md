## 3. FORK 3 · семантический слой · зафиксировано

| Параметр | Значение |
|----------|----------|
| Корпус | 10 контрольных предложений, классы: число / отрицание / условие / причинность / редкий термин |
| Преобразования | T2a (перефраз-сжатие), T2b (перефраз-разворот стиля), T3 (RU→EN→RU) |
| Судьи | MECHANICAL (независимый код, stdlib, Decimal) + R1(7170) + R2(7171) + R3(7172), SAME_MODEL_SEPARATE_PROMPT = JUDGE_STUB (разрешённый минимум ТЗ) |
| Агрегация | majority по 4 судьям, ничья → более строгий вердикт |
| Вердикт предложения | худший вердикт по его трансформациям |
| Вердикт корпуса | PASS = все SOFT; FAIL = ≥2 предложений BREAK или ≥25% BREAK-трансформаций; иначе PARTIAL |
| Результат v0.2.3 | PARTIAL (1 BREAK из 30, дефект зарегистрирован) → CONDITIONAL PASS |
| История | ленты не переписываются; исправление — новой лентой в v0.2.4 |

## 4. EXPERIENCE_SCORE · протокол калибровки (FR-3)

**Значение v0.2.2 = 87.0 — помечено ИСТОРИЧЕСКИМ CANDIDATE.** До завершения калибровки нигде не используется как подтверждённое.

Разделение величин:
- **s_i** — сила свидетеля i (из стены свидетелей; жанр теоремы выше метафоры; метафора не добавляет силы, только смысл).
- **a_i** — действия: наблюдаемые прогоны в среде (запуски, артефакты, возвраты в среду). Считаются в штуках, не в годах.
- **w_i** — веса связи s_i и a_i. Явно разделить: какие веса экспертные (назначены рукой и помечены), какие будут измерены возвратом в среду.

Протокол калибровки:
1. Фиксировать предсказание (число + условие его проверки) ДО прогона.
2. Прогнать в среде; зафиксировать факт в ленте.
3. Сверить предсказание с фактом; разница = поправка веса.
4. Вес переходит из экспертных в измеренные только после ≥3 независимых сверток.
5. Ярлык CANDIDATE снимается решением владельца + аудитора по чеклисту.

## 5. Границы честности v0.2.3

- Семантический судья = та же модель, отдельный промпт + отдельный seed (JUDGE_STUB). Реальный независимый судья — другой провайдер/модель/человек — задача v0.2.4+.
- Механический судья = независимый код (stdlib, Decimal, маркерные списки) — независимость от генератора честная.
- Детерминизм: seed = 7170 (число языков планеты из диалога); двойной прогон дал совпадение хеша ленты.
- Сводный PDF всего пакета — желательный критерий, отложен честно.

## 6. Правило остановки

Если хотя бы один блокирующий критерий приёмки не выполнен — релиз остаётся **CONDITIONAL PASS** и не объявляется полным. Текущее состояние: FORK 3 выполнен (протокол + 3 прогона + majority + сырые ленты), но полный PASS блокируют: внешний судья W3 и невоспроизводимость в среде машинных чисел математического ядра.
