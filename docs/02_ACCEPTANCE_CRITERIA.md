# КРИТЕРИИ ПРИЁМКИ v0.2.3

## Обязательные (блокирующие)

1. **FORK 3**
   - Существует протокол независимого судьи.
   - Проведено ≥ 3 прогона.
   - Есть majority-вердикт + сырые ленты.
   - Критические ошибки (отрицание, число, причинность, условие, редкий термин) помечены отдельно.

2. **Стена свидетелей**
   - Таблица «Свидетель → что подтверждает → жанр» присутствует в манифесте и контракте.
   - Нет формулировок вида «все подписали одну формулу».

3. **Синхронизация**
   - Ни одно утверждение манифеста не противоречит контракту или ленте.
   - EXPERIENCE_SCORE везде либо 87.0, либо явно помечен как исторический.

4. **Воспроизводимость**
   - ZIP запускается из чужого cwd.
   - Ключевые числа совпадают (Банах, Пуанкаре 135, zlib и т.д.).

5. **История**
   - Старые ленты на месте + sha256.

## Желательные

- Реальный отдельный судья (не заглушка).
- Первые черновые веса для EXPERIENCE_SCORE.
- Сводный PDF всего пакета.

## Правило остановки
Если хотя бы один блокирующий критерий не выполнен — релиз остаётся CONDITIONAL PASS и не объявляется полным.
