## ТАБЛИЦА ПЕРЕХОДОВ (10 СОСТОЯНИЙ · 8 ПЕРЕХОДОВ · 2 ФИНАЛА)

```
BOOT    --ok-->    SEAL     корень найден: run_all.py + scripts/
SEAL    --ok-->    RUN_R1   печать артефакта цела (или честный пропуск)
        --no-->    FAIL     печать не совпала с якорем
RUN_R1  --ok-->    RUN_R2   чистый прогон 1: exit 0
RUN_R2  --ok-->    COMPARE  чистый прогон 2: exit 0
COMPARE --ok-->    CHAIN    хеш ленты двух прогонов равен = детерминизм
        --no-->    FAIL     хеши разошлись
CHAIN   --ok-->    VERDICT  хеш-цепь ленты цела (файл-файл из поля «хеши»)
        --no-->    FAIL     цепь разорвана
VERDICT --ok-->    TAPE     вердикт корпуса не FAIL
TAPE    --ok-->    CLOSED   лента автомата записана и подписана
```

ЛЮБОЙ ПЕРЕХОД ПО `--no-->` = FAIL + ЛЕНТА-СВИДЕТЕЛЬ (R-05: ОШИБКА = СВИДЕТЕЛЬ).
