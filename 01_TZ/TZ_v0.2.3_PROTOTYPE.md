**Статус:** ПРОТОТИП  
**Дата:** 2026-11-17  
**Базовый релиз:** v0.2.2 (CONDITIONAL PASS)  
**Цель релиза:** закрыть семантический слой (FORK 3) и привести стену свидетелей к форме «восемь разных свидетельств».

---

## 1. Цель и границы

### 1.1. Цель
Получить **полный PASS** детерминированного + семантического ядра за счёт:
1. Независимого судьи в FORK 3 (n ≥ 3 прогона, majority).
2. Перестройки стены свидетелей (M5, M12).
3. Калибровки EXPERIENCE_SCORE_CANDIDATE (хотя бы протокол калибровки).
4. Финальной синхронизации всех документов под единый контракт v0.2.3.

### 1.2. Вне границ (не делать в v0.2.3)
- Численная реализация потока Риччи.
- Полноценный независимый LLM-судья (если нет доступа — оставить протокол + заглушку).
- Переписывание манифеста с нуля.
- Новые математические теоремы.

### 1.3. Критерий приёмки релиза
- [ ] FORK 3 выдаёт воспроизводимый вердикт PASS / PARTIAL / FAIL / UNKNOWN с независимым судьёй (или честной заглушкой + протоколом).
- [ ] Стена свидетелей переписана как таблица «Свидетель → что именно подтверждает».
- [ ] EXPERIENCE_SCORE имеет явный протокол калибровки (даже если числа остаются CANDIDATE).
- [ ] Все документы синхронизированы (манифест / контракт / ленты / миграция).
- [ ] ZIP проходит независимый прогон свидетелем без падений и с совпадением ключевых чисел.

## 2. Функциональные требования

### FR-1. Независимый судья FORK 3
- Зафиксировать исходный корпус (хеш, версия, контрольные утверждения).
- Зафиксировать преобразования T2 (перефраз ×2) и T3 (RU→EN→RU).
- Судья ≠ модель, создававшая преобразование (минимум — отдельный промпт + отдельный seed / отдельный провайдер, если доступен).
- n ≥ 3 независимых прогона.
- Вердикт по majority + сохранение всех сырых лент.
- Критические ошибки (отрицание, число, причинность, условие, редкий термин) выделяются отдельно.

### FR-2. Стена свидетелей v0.2.3
Таблица вида:

| Свидетель     | Что реально подтверждает                          | Жанр          |
|---------------|---------------------------------------------------|---------------|
| Банах         | Единственность неподвижной точки при условиях     | Теорема       |
| Ляпунов       | Локальная устойчивость                            | Анализ        |
| Марков        | Стационарное распределение + условия сходимости   | Теорема       |
| Колмогоров/MDL| Формальная сложность описания (относительно класса)| Конструкция  |
| Пуанкаре      | Возврат при конечной мере + сохранении меры       | Теорема       |
| Нётер         | Связь симметрий и законов сохранения              | Теорема       |
| Гёдель        | Ограничения формальных систем                     | Теорема + МЕТАФОРА |
| Перельман     | Конкретный результат + человеческое действие      | Факт + АНАЛОГ |

### FR-3. Протокол калибровки EXPERIENCE_SCORE
- Явно разделить: s_i (сила свидетеля), a_i (действия), w_i (веса).
- Зафиксировать, какие веса экспертные, какие будут измеряться.
- Оставить ярлык CANDIDATE до реальной калибровки.

### FR-4. Регрессии и история
- Все предыдущие ленты (v0.1, v0.2, v0.2.1, v0.2.2) сохраняются.
- sha256 старых лент фиксируются в новой ленте.
- Ошибочные эксперименты не удаляются.
