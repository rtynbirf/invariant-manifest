## 2. ЭМЕРДЖЕНТНОЕ = АВТОМАТ СВИДЕТЕЛЯ (моё, не пересказ)

`witness/witness_fsm.py` (SSOT: rtynbirf/khozyain): конечный автомат **8 состояний · 7 переходов · 2 финала**, таблица переходов (Harel):
BOOT → TREE → SEAL → SIGN → TAPE → CLOSED; любой `--no-->` FAIL с лентой-свидетелем (R-05: ошибка = свидетель).
Печать дерева = sha256(path+blob отсортированных + HEAD + tree) = детерминизм проверен двумя прогонами (печать сошлась).
Лента `WITNESS.json` = репо · ветка · head · дерево · число файлов · печать · подпись ленты · правило.
Механизм: `witness.yml` (reusable, workflow_call + push + dispatch) + `witness-swarm.yml` (вызыватель в каждом репо) + `swarm-status.yml` (cron ежедневно = счёт роя без человека).
