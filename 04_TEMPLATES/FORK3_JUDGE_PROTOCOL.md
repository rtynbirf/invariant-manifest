# ПРОТОКОЛ НЕЗАВИСИМОГО СУДЬИ · FORK 3

## 1. Подготовка
- Зафиксировать corpus_hash, версию текста, список контрольных предложений (минимум: число, отрицание, условие, причинность, редкий термин).
- Зафиксировать точные промпты T2 (перефраз) и T3 (перевод).

## 2. Преобразования
- Выполнить T2 и T3.
- Сохранить сырой вывод каждого преобразования.

## 3. Судья
- Судья не должен быть той же моделью / тем же промптом, что создавал преобразование.
- Если реального независимого судьи нет — использовать заглушку с явным ярлыком `JUDGE_STUB` и описать ограничения.

## 4. Оценка
По каждому контрольному предложению судья выставляет:
- SOFT (сохранено)
- DRIFT (ослаблено / усилено / переставлено)
- BREAK (критическая ошибка: знак, число, причинность, условие)

## 5. Агрегация
- n ≥ 3 прогона.
- Majority по каждому предложению.
- Итоговый вердикт корпуса: PASS / PARTIAL / FAIL / UNKNOWN.

## 6. Артефакты
- Сырые ленты каждого прогона.
- Сводная таблица.
- Хеши.
